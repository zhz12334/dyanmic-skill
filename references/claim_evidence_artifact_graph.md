# Claim–Evidence–Artifact Graph

A reproduction target is a scientific claim, not merely a picture.

## Claim types
- quantitative scalar/table
- qualitative trend/ranking
- modal/eigenpair
- transient/frequency-domain
- spatial field
- nonlinear transition/bifurcation
- stochastic/statistical
- experimental observation
- methodological/algorithmic

## Required links
Each critical claim should link to:
1. paper location;
2. equations/assumptions;
3. parameter IDs;
4. data/figure/table targets;
5. implementation modules;
6. tests/metrics/tolerances;
7. calibration or validation role;
8. evidence-producing run IDs;
9. final verdict.

A plot can support multiple claims, and a claim may require multiple plots/tables. Do not equate figure reproduction with claim reproduction.
